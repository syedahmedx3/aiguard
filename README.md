# @syedahmedx3/aiguard 🛡️

> An AI-powered access firewall for local file systems.

`aiguard` provides an intelligent, glob-based security layer to prevent path traversal, block unauthorized access to sensitive files (like `.env`), and securely manage file reads in Node.js environments. It is highly optimized for enterprise architectures, making it an excellent fit for securing custom module directories and heavy-lifting environments like Odoo.

## Installation

```bash
npm install @syedahmedx3/aiguard
```
